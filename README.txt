Daily Habit Tracker (installable web app)

1. Upload this whole folder to a free host that serves https, for example Netlify Drop (app.netlify.com/drop) or GitHub Pages.
2. Open the address it gives you in Chrome on your phone.
3. Tap the three dots, then Install app (or Add to Home screen).

Your entries are stored on the phone. Use the Export tab to back up now and then.
